# goal-alignment

**The loop, and the heart of the repo.** Layers on `plain-english` and `explain`.

One idea: do all the thinking *before* the agent starts looping. Settle every decision you need to know about, prove every prerequisite live, and co-write a plain-english brief (Problem, Implementation, Verification) you can read aloud. Then hand the agent a self-correcting loop whose only "done" criteria are fast checks that actually appear in the transcript, judged each turn by an independent grader that can be fooled by a confident claim, plus a fresh-context critic. The end-to-end check through the real UI comes after the loop is green. Preparation is the product; the loop is the cheap part.

See [SKILL.md](SKILL.md) and the [piv-template.md](piv-template.md) you fill in per round.
