# explain

**Understanding mode.** Layers on `plain-english` for when a reply did not land and you want to understand, not just get it done. It replaces the older `teach`.

One idea: find the one piece you are missing and fill only that, built on something you already know, one idea per reply, until you can act. Saying "explain" again makes the next reply smaller and more basic, never longer. Each idea that lands goes into your understanding log, so it is never explained twice. It can also draw a short picture page, one slide per idea.
