# drill-down

**The list.** Layers on `plain-english` and `chief`. The one place you see everything in flight at once.

One idea: when you ask, the chief reads every box live and writes one short numbered list of what needs you now. Each line says the work in plain words, where it stands, and the exact words that unblock it, in quotes. You answer by number ("1. merge"), and that answer covers that line once. Asked inside any other box, the same list covers only that box's work.

The list has a fixed shape, opening with `Needs you: <n>`, so chiefman, the Mac app in this repo, can show it as cards with one-click answers. See [SKILL.md](SKILL.md).
